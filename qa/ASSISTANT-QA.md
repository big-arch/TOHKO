## Границы проверки

HTML, CSS, JS и публичный config подавались из локальной финальной сборки через Playwright routing под production Origin. Запросы Supabase проходили по реальной сети; этот домен ни одним route-handler не перехватывался. Это проверка перед публикацией, а не утверждение, что та же сборка уже развернута на Pages.

Начальный Edge-прогон в sandbox получил `ERR_NETWORK_ACCESS_DENIED`; после штатного сетевого разрешения бесплатный GET в Edge завершился таймаутом. Успешный live-прогон выполнен в Chrome/Chromium. TLS-проверка не отключалась, сервер не проксировался и модель не подменялась. Неудачные health-пробы не отправляли новый платный вопрос.

Внешние CDN шрифтов и иконок отключены только в тестовом браузере, чтобы их локальная недоступность не задерживала загрузку страницы. Поэтому этот прогон проверяет панель с резервным шрифтом; доступность Manrope из CDN здесь не подтверждается.
