# Помощник ТОНКО: фото и диалог, 16 ноября 2026

Проверена локальная реализация. Публикация и платные запросы не выполнялись; все ответы в browser QA подменены локальным mock. Качество формулировок новой инструкции модели нужно оценивать отдельно после деплоя, не выдавая этот отчёт за живую проверку OpenAI.

## Данные и ограничения

Последний проверенный снимок: 915 текстовых записей, 117 уникальных фото (46 из старой галереи, 13 из `style-photos.json`, 58 из `package-looks.json`). Категории: 19 мужских, 2 парных, 96 женских. Для 53 фото DEN подтверждён; у остальных поле `den` принудительно `null`. JSON — 1 125 431 байт, публичная и встроенная копии совпадают. Сборка дополнительно удаляет повтор одного файла между старой галереей и новым реестром, сохраняя более полные проверенные данные.

Порог snapshot остаётся 2 МиБ; максимум 2 500 текстовых записей и 600 фото. Сервер передаёт до шести компактных описаний фото внутри прежнего контекста 10 500 символов. Ответ содержит до трёх карточек. Модель и лимиты не менялись: `gpt-6-luna`, `store:false`, `reasoning.effort:none`, 900 выходных токенов, общий cap 250 попыток/сутки. Никаких новых ключей, сетевого поиска, инструментов или анализа изображений модель не получает.

## Фактически проверенные сценарии

| Запрос/проверка | Результат локального кода |
| --- | --- |
| «Покажи фото мужчин 20 DEN» | Два подтверждённых фото Glamory Classic20; случайные похожие фото не добавляются |
| «Покажи фото для пары» | Два парных кадра; явная пометка неизвестного DEN |
| «Покажи фото для пары 20 DEN» | `no_match`, пустой список фото; никакой подмены мужскими/женскими одиночными кадрами |
| «Покажи фото Wolford Individual 20» | Четыре точных фото доступны в контексте; модель может выбрать максимум три |
| «Покажи фото Adrian» | Старые фотографии Adrian из публикации Activskin; Minimi Adriana 20 не попадает по совпавшей части слова |
| «А сушить?» после вопроса о стирке | В контексте справка о полотенце, сушке на воздухе и избегании нагрева; не только совет прочитать ярлык |
| «Покажи», «А для пары?», «А 40?» | Недавние категория/плотность сохраняются или явно заменяются уточнением |
| «Покажи ещё» | Уже показанные ID и повтор того же локального файла исключаются в пределах доступной истории |
| «Какой DEN на втором фото?» | История передаёт порядок, ID и метку DEN; соответствующая запись возвращается модели для сверки |
| Внешняя картинка, HTML, `javascript:`, чужой ID | Не становятся фотографией; подписи остаются обычным текстом |
| Неизвестный DEN | Число из заголовка/имени файла не становится характеристикой или фильтром |
| Ошибка URL/размера/схемы реестра | Обновление отклоняется, остаётся предыдущий проверенный snapshot |

Память ограничена восемью прежними сообщениями / 6 000 символами на запрос и 24 сообщениями в текущей вкладке. Это не память между устройствами или вкладками. Реестр неполный: отсутствие фото означает отсутствие в этой подборке. Размерные таблицы не добавлены; цены, актуальное наличие, лечебная компрессия и DEN по виду не угадываются.
