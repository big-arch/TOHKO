## Интерфейс и проверки

- Общий обзор содержит отдельные секции всех 25 брендов по алфавиту, по четыре изображения каждого (88 видимых карточек). Кнопка продолжения добавляет изображения только внутри соответствующего бренда.
- В выбранном бренде показываются до 36 изображений, далее работает продолжение. Упаковки не перемешиваются между производителями.
- `qa/check-packaging.py`: PASS в реальном Edge. Проверены все 25 вариантов выбора бренда, согласованность счётчиков, открытие по URL, поиск Smart Box, совместный фильтр DEN, пустое состояние, увеличение 2×, стрелки, Esc и возврат фокуса.
- Глубокая ссылка на упаковку вне начального обзора открывается даже при несовместимых сохранённых параметрах поиска: отображается бренд этой упаковки.
- Ширины 320, 390, 768 и 1440 px без горизонтального переполнения. Новые изображения Giulia реально загружены браузером, ошибок JavaScript нет.
- Без JavaScript доступны все 501 изображение и алфавитные переходы между брендами.
- Скриншоты `pack11-desktop.png` и `pack11-mobile.png` находятся в локальной папке QA и не публикуются с сайтом.

Браузерная проверка не подтверждает коммерческое наличие товара: сайт показывает архив оформления.
