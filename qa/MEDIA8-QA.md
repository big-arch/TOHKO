# ТОНКО · фотографии, чтение новостей и плеер · 16.11.2026

## Выполнено

- Шесть самостоятельно найденных изображений: три диптиха образов Swedish Stockings, новая упаковка Swedish Stockings, OMSA Attiva 40, оборот Gabriella Mat Effect. Источники указаны в editorial-media.json. Изображения не выдаются за свободно лицензированные.
- На главной отдельные подборки образов и упаковок; в галерее широкие фотографии показываются целиком. 62 записи в реестре, 197 responsive-вариантов.
- Внутреннее окно новости: бумажный фон, винный акцент, иллюстрация с подписью, заголовок, дата, короткий RSS-анонс, отдельный совет ТОНКО и необязательная ссылка на источник. Для отсутствующего анонса честное пустое состояние. Полные статьи не копируются.
- Содержательный редакционный пересказ одной проверенной публикации хранится в news-digests.json; новые записи автоматически получают короткие анонсы RSS. Прямая публикация при дублировании имеет приоритет перед Google News. Обычные ссылки и чтение без JS доступны в news.html.
- URL открытой новости, Back/Forward, Escape, возврат фокуса и блокировка прокрутки фона.
- 18 роликов: 11 YouTube, 5 Vimeo, 2 Snag с официального CDN в HTML5-плеере. Загрузка только по клику; одновременно один плеер. Добавлены две видеодетали Vimeo и два ролика Snag.
- Позиция просмотра сохраняется локально, завершённые ролики начинаются заново. Обычный/приватный режим YouTube выбирается явно. ТОНКО не получает пароль и не обещает постоянный вход в Google.

## Проверки

- `python scripts/check-site.py`: все локальные ссылки и ресурсы 34 HTML-страниц.
- `python -m unittest discover -s qa -p test_news.py`: 13 тестов, включая короткие анонсы, дубли, сохранение данных при сбоях и допустимые URL.
- `node qa/test_video_memory.cjs`: сохранение/сброс позиции, изоляция роликов, повреждённые данные, недоступное хранилище, режим плеера при ошибке записи.
- `qa/check-media8.py`, Playwright + Edge: внутреннее чтение, история, фокус, прямой URL, упаковки, 18 карточек, сохранение режима и возобновление, экраны 1440/390/320, отсутствие JS-ошибок.
- `qa/check-media8-playback.py`: настоящее видео Snag в плеере ТОНКО без подмены ответов: время 6.047 → 8.061 с; после закрытия и перезагрузки продолжено с 7 с. Снимок `qa/media8-native-playing.png` локальный, не публикуется.
- Оба новых Snag-потока отдельно воспроизводились: длительность 19.904 и 9.533 с, время увеличивается, 606×1080.
- Финальное независимое ревью обнаружило две ошибки: выбранный режим при недоступном localStorage и восстановление окна при Forward. Обе исправлены и проверены регрессионными тестами.

## Граница проверки платформ

Vimeo в текущем автоматизированном Edge показал `We couldn't verify the security of your connection` / Cloudflare. Проверка не обходилась. Реальное воспроизведение Vimeo в этом запуске не подтверждено; при ошибке доступна кнопка альтернативного плеера. YouTube также может потребовать вход или запретить встраивание. Рабочий вариант без аккаунта — HTML5 с видео Snag, проверенный выше.

## Сборка

`build-editorial.py` → `build-experience.py` → `build-videos.py` → `optimize-images.py` → `build-home-news.py`.
По расписанию GitHub Actions запускает сборщик новостей и последнюю стадию; окно чтения и news.html получают новый снимок. Частота по-прежнему 15 минут с возможными задержками GitHub/источников.
