# Видео · выпуск 17

Проверено 17 ноября 2026 года, локально и без доступа к внешним сервисам.

## Результат

- В текущем снимке 96 видео, 31 автоисточник и 38 пунктов каналов: автоисточники вместе с авторами ручной подборки. OonaLinna доступен с нулевым количеством и ссылкой на канал. У Legslavish есть собственный пункт. Legs by Layla и Layla Fashion разделены.
- Каналы сопоставляются по исходным URL, явно настроенным алиасам и идентификаторам источников, не по похожим именам. Для Swedish Stockings используется явно заданный `publisherHost`; исходные ссылки отдельных карточек сохранены. Совпадающие имена разных каналов различаются адресом в меню. Количества отражают весь каталог, а не текущий набор фильтров.
- По умолчанию карточки упорядочены по `publishedAt` от новых к старым. Можно выбрать обратный порядок. Неизвестные и некорректные даты остаются внизу в обоих режимах; равные моменты сохраняют исходную взаимную последовательность. Статический HTML использует тот же порядок. Исходный JSON и стартовый Snag-плеер не переставлялись.
- У всех карточек и у выбранного ролика есть исходная дата либо надпись «Дата публикации не подтверждена». У архивных роликов сохранена отметка архива. `time.datetime` содержит полное исходное ISO-значение, а видимый день соответствует дню в источнике.
- «Новое» означает `0 ≤ сейчас − publishedAt < 7 суток`. Дата добавления/проверки не используется. Будущие и неизвестные даты не помечаются. Дата без времени сравнивается как начало дня UTC; время исходной публикации при этом не выдумывается и не выводится. Метки пересчитываются при открытии, `pageshow`, смене видимости и по таймеру ближайшей границы. В статическом HTML они скрыты, чтобы кэш страницы не показывал устаревшие метки без JavaScript.
- Выбор канала и порядка сохраняется в URL (`channel`, `sort=oldest`). Поиск, тема, язык, плеер, «Смотреть позже», `?video=` и Snag без аккаунта сохранены. Новые поля имеют отдельные связанные подписи, видимый фокус и нативное клавиатурное управление.
