Конфиденциальность

Дата редакции: 16 ноября 2026 года. Справочный сайт ТОНКО не создаёт аккаунты посетителей. Подбор в калькуляторе работает локально; сообщения ИИ-помощнику отправляются на сервер только после нажатия «Отправить».

Какие данные используются

Погода, задача, рост и вес обрабатываются только в вашем браузере для показа рекомендации. Эти значения не сохраняются и не передаются владельцу сайта.

Локальное хранилище

Отметки чеклиста сохраняются в локальном хранилище браузера под ключом denie care. Они остаются на вашем устройстве. Кнопка сброса удаляет текущие отметки.

Внешние ресурсы

Для отображения шрифта Manrope и иконок Phosphor используются Google Fonts и Unpkg. При загрузке этих ресурсов внешний сервис может получить стандартные технические данные запроса, включая IP адрес и тип браузера.

Файлы cookie и аналитика

Сайт не устанавливает собственные файлы cookie, не использует рекламные идентификаторы и не содержит счётчики аналитики.

Сохранённые файлы

Рекомендация скачивается как текстовый файл по вашему действию. Вы самостоятельно выбираете место хранения и управляете этим файлом.

Удаление данных

Вы можете удалить локальные данные сайта через настройки браузера. Удаление данных сайта очистит сохранённый чеклист.

Подборки и место чтения

Сохранённые статьи, фотографии, размер текста и место чтения хранятся локально в этом браузере. Они не отправляются в базу ТОНКО и не синхронизируются между устройствами. Очистка данных сайта удаляет эти настройки. В приватном режиме браузер может не сохранять их после закрытия окна.

Видеоплееры

Превью размещены на сервере ТОНКО. Видео Snag воспроизводятся встроенным HTML5-плеером; медиапоток поступает с snagtights.com после нажатия. Браузер передаёт CDN бренда технические данные для доставки видео, включая IP-адрес. Vimeo и его API (player.vimeo.com) подключаются только при запуске ролика Vimeo; используется параметр dnt=1, но технические данные для доставки видео всё равно передаются платформе. Проигрыватель youtube-nocookie.com и официальный YouTube IFrame API с youtube.com подключаются после нажатия «Смотреть на сайте»: при этом браузер обращается к серверам YouTube и передаёт технические данные, в том числе IP-адрес. Режим повышенной конфиденциальности не означает отсутствия передачи данных. Ссылки на оригинал и каналы в пункте «Источник» открывают внешний сервис.

«Смотреть позже», позиция просмотра и выбор режима YouTube сохраняются только в localStorage этого браузера. При выборе обычного режима подключается youtube.com вместо youtube-nocookie.com; браузер и Google управляют доступом к существующему сеансу аккаунта. Подборка не отправляется в базу ТОНКО и не синхронизируется между устройствами; очистка данных сайта удаляет её.

ИИ-помощник ТОНКО

При отправке вопроса текст сообщения и до восьми предыдущих сообщений этой беседы передаются серверной функции в Supabase и затем OpenAI для подготовки ответа. Помощник также получает подходящие выдержки из открытых материалов ТОНКО. Не отправляйте пароли, платёжные данные или другую конфиденциальную информацию.

История беседы хранится в sessionStorage текущей вкладки. Кнопка «Очистить» удаляет её из интерфейса и хранилища. Сервер ТОНКО не записывает тексты бесед в свою базу; запросы к OpenAI выполняются с параметром store:false. Обработку технических журналов сервисами описывают политика Supabase и политика OpenAI.

Для ограничения частоты запросов сервер сохраняет счётчики и хеш технического сетевого адреса, вычисленный с серверным секретом. Сам адрес в этой таблице не сохраняется; устаревшие счётчики удаляются при следующих запросах. Браузер, Supabase и OpenAI получают необходимые технические данные для доставки запросов.

Ответы генерирует ИИ: он может ошибаться. Каталог упаковок является справочным архивом, а не подтверждением цены, наличия товара или таблицы размеров. Помощник не подбирает медицинскую компрессию и не заменяет консультацию специалиста.
