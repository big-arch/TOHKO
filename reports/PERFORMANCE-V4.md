# ТОНКО: адаптивные фотографии

Применены руководства Modern Web Guidance `optimize-image-priority` и `performance`, полученные официальным CLI через `search` и `retrieve`. Источник: https://developer.chrome.com/docs/modern-web-guidance/get-started?hl=ru . Глобальный плагин не устанавливался; рекомендации использованы для конкретного изменения сайта.

## Изменения

- 146 WebP-вариантов для 48 фотографий: ширины 320, 640, 960 и 1440 px, без увеличения небольших исходников. Качество кодирования 88.
- Статические фотографии получили srcset/sizes и асинхронное декодирование. Обложки загружаются сразу с fetchpriority=high.
- Галерея выбирает файл под ширину колонки и плотность экрана; режим «Крупнее» обновляет размеры. Первые две фотографии загружаются сразу, остальные — отложенно.
- Оригиналы сохранены без изменений. Просмотрщик и «Под лупой» используют полные изображения.
- Добавлена воспроизводимая третья стадия сборки scripts/optimize-images.py. Готовые варианты публикуются статически.

## Замер до и после

Локальный Chromium, новый изолированный контекст, 390×844 CSS px, DPR=2. В каждом сценарии последовательно открывались главная и галерея до networkidle, без прокрутки. Суммировался encodedBodySize ресурсов с initiatorType=img. Одинаковое число запросов: 2 на главной, 9 в галерее. Общий контекст сохраняет кэш между этими двумя переходами в обоих замерах.

| Страница | До, байт | После, байт | Сокращение |
| --- | ---: | ---: | ---: |
| Главная | 618 694 | 119 610 | 80,7% |
| Галерея | 5 473 414 | 295 372 | 94,6% |

Это объём фотографий, загруженных в данном сценарии, не вес всего сайта и не измерение скорости на реальном мобильном интернете. DOMContentLoaded на локальном сервере: 751/743 мс для главной и 12/16 мс для галереи; эти колебания не доказывают ускорение. Полевые LCP/INP не измерялись.

## Проверка

Проверены синтаксис JavaScript и ссылки в 32 HTML. Все 146 вариантов загрузились в браузере с правильной шириной. Проверены экраны 320, 768 и 1440 px, сохранение фотографий, режим крупной сетки и открытие полного оригинала. «Под лупой» сохраняет исходник и увеличение. Ошибок JavaScript и горизонтального переполнения не найдено. Повторный запуск оптимизатора не меняет HTML. Оригиналы не изменены (git diff пуст для assets/editorial). Результат публикации фиксируется в рабочем состоянии задачи.
