# News and looks implementation plan

**Goal:** Подключить обновляемую новостную ленту и семь фотографий к ТОНКО.
**Architecture:** Python собирает ограниченный JSON и HTML; браузер читает только свой JSON; один Pages workflow публикует код и обновления по расписанию.
**Tech Stack:** Python standard library, curl, HTML/CSS/JavaScript, существующий Pillow builder.
**Spec:** ../specs/2026-11-16-news-looks-design.md

## Ограничения и риски

Никаких секретных ключей и новых платных сервисов. Заголовки оригинальные, дата источника отделена от проверки. Не терять последнюю удачную ленту при сбоях. Не исполнять внешний HTML. Не менять существующую историю Git и несвязанный отчёт обзора.
