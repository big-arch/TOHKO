# ТОНКО

Независимая русскоязычная энциклопедия колготок, легинсов, капрона и чулочной индустрии.

Сайт: **https://big-arch.github.io/TOHKO/**

## Локальный запуск

Из корня репозитория:

```sh
python -m http.server 4185 --directory tights-guide
```

Открыть http://localhost:4185/. Сервер нужен для загрузки реестра логотипов. Сборка и установка npm-пакетов не требуются.

## Структура

- `tights-guide/` — публикуемый сайт, 33 HTML-файла, стили и JavaScript.
- `tights-guide/data/brands.js` — исходный каталог 43 марок и моделей.
- `tights-guide/data/brand-research.js` — уточнения историй и источники; статус проверки отделён от наличия товаров.
- `tights-guide/data/photos.js` — фотографии галереи, авторы, лицензии.
- `tights-guide/data/logo-sources.json` — происхождение 20 оригинальных логотипов.
- `PRODUCT.md`, `DESIGN.md` — согласованное направление продукта и оформления.
- `reports/ТОНКО — аудит и первый выпуск.md` — оценка, изменения, ограничения и предложения.
- `scripts/story_content.py` — шесть оригинальных статей и девять событий архивной хронологии с первоисточниками.
- `tights-guide/experience.js`, `experience.css` — журнал, чтение, интерактивная история, увеличение фотографий и умеренные анимации.
- `reports/ТОНКО — журнал и интерактивный архив.md` — разбор десяти сайтов и результат третьего выпуска.

## Обновление редакционных страниц

Сайт раздаётся как готовые статические файлы. При изменении шаблонов или контента запускайте стадии по порядку:

```sh
python scripts/build-editorial.py
python scripts/build-experience.py
python scripts/build-videos.py
python scripts/optimize-images.py
python scripts/check-site.py
```

Первая стадия собирает основные тематические страницы. Вторая создаёт журнал, статьи и мастерскую. Третья собирает видеотеку, обновляет общую навигацию и добавляет связанные материалы. Изображения хранятся локально; их исходные адреса и подписи находятся в `data/editorial-media.json`. Повторная сборка не дублирует разделы.

Видеотека хранится в `tights-guide/data/videos.json`: YouTube ID, русское и исходное название, канал, темы, язык, ссылка и дата проверки. Проверяйте новые ролики и возможность их публикации перед добавлением. `build-videos.py` создаёт HTML и индекс `data/videos.js` для поиска. Ссылки доступны без JavaScript; плеер подключается только по нажатию. Избранные видео сохраняются только в браузере.

Основное действие в видеотеке — «Смотреть на сайте». Один встроенный проигрыватель YouTube заменяет текущее видео при переключении; ссылки на канал и оригинал находятся в свёрнутом пункте «Источник». Официальный IFrame API загружается по первому нажатию и сообщает об ошибках и блокировке автозапуска. Если API недоступен, остаётся обычный iframe. Закрытие удаляет плеер, останавливает звук и отменяет отложенные действия. Проверки интеграции: `qa/check-inline-player.js` (Playwright, локальный сервер на порту 4185); результаты и пределы проверки — `qa/INLINE-PLAYER-QA.md`.

Выпуск 06 добавляет Vimeo: три фильма Swedish Stockings из серии Journey of a Thread идут первыми в видеотеке. `provider: "vimeo"` и числовой `providerId` задают второй плеер; для прежних записей используется YouTube. Фильтр «Без YouTube · Vimeo» и кнопка альтернативных видео после ошибки YouTube ведут к этим трём фильмам, а не к копиям прежних обзоров. SDK обеих платформ загружаются только после клика. Публичные ограничения YouTube не обходятся; все 11 обзоров сохранены с исходными ссылками. Проверка реального воспроизведения, фото и мобильной версии: `qa/check-media-v6.js` и `qa/MEDIA-V6-QA.md`.

С выпуска 05 мужской раздел посвящён одежде, сочетаниям и посадке. Статья 18+ снята с публикации; `fetish.html` оставлен как нейтральная страница с `noindex` для старых ссылок. Исключённые фотографии удалены из публикуемой папки, история Git не переписана.

Последняя стадия готовит адаптивные WebP-превью и добавляет `srcset`, `sizes` и приоритет обложек. Для неё нужен Pillow (`python -m pip install Pillow`). Готовые файлы включены в репозиторий, поэтому для просмотра и публикации Pillow не требуется. Оригиналы остаются в `assets/editorial`, варианты — в `assets/responsive`; просмотрщик и увеличение используют оригиналы.

## Проверка и публикация

```sh
python scripts/check-site.py
```

GitHub Actions проверяет локальные ссылки и синтаксис JavaScript, затем публикует только `tights-guide/` в GitHub Pages после push в `main`. Исследования и локальный кэш не входят в сайт. Workflow: `.github/workflows/pages.yml`.

Избранные модели, фотографии, статьи и место чтения хранятся в браузере конкретного устройства. Публичный сайт доступен с разных устройств; синхронизация подборок между ними не реализована.

## Материалы

Авторы фотографий, лицензии и источники историй доступны на странице `sources.html`. Логотипы принадлежат соответствующим правообладателям. Новый графический логотип ТОНКО отложен по решению владельца; используется текстовое название.
